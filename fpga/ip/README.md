# fpga/ip — the custom FPGA IP

| path | what |
|---|---|
| `src/uhd_ip/` | the UHD data-plane cores: RTL, simulations, packaging (`src/uhd_ip/README.md`) |
| `repo/uhd_ip/` | those cores packaged as Vivado IP (`user.org:uhd:<core>:1.0`). Generated by `make -C fpga package`: never edit |
| `src/cmac_100g/` | the 100G Ethernet MAC + transceiver wrapper, as RTL (`src/cmac_100g/README.md`) |
| `repo/dual_rf_adc_iq_merger_1.0`, `repo/dual_channel_rf_adc_iq_packer_1.0` | the RFSoC 4x2's dual RF-ADC I/Q joiners, packaged in place (`hdl/`, `tb/`, `package_ip.tcl`) |

The block designs import their IP from `repo/`. The 100G MAC is not in the
block design: it is instantiated in each build's generated RTL top.

Packaging and the simulations need Vivado 2021.1.
