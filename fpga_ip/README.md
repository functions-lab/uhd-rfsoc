# fpga_ip — the custom FPGA IP

| path | what |
|---|---|
| `ip_design/uhd_ip/` | the UHD data-plane cores (udp_streamer, udp_player, axis_pkt_arb, ch_interleave, tx/rx_beamformer): RTL, xsim testbenches, `make package` |
| `ip/uhd_ip/` | those cores packaged (`user.org:uhd:<core>:1.0`): generated by `make package`, never edited |
| `ip_design/cmac_100g/` | the 100G CMAC + GT wrapper RTL; instantiated in each build's generated RTL top, not in the block design |
| `ip/iprepo/dual_rf_adc_iq_merger_1.0`, `ip/iprepo/dual_channel_rf_adc_iq_packer_1.0` | the dual RF-ADC I/Q joiners of the RFSoC 4x2 designs, packaged in place (HDL in `hdl/`, testbench in `tb/`, `package_ip.tcl`) |

`ip_design/` (sources) and `ip/` (packaged) sit side by side so the packaging
scripts and the board build flows (`../fpga_board`) find each other by
relative path; the build scripts name exactly the repositories they need.
Everything here needs only Vivado 2021.1. Each subdirectory's `README.md` /
`AGENTS.md` has the details.
