# fpga_ip — the custom FPGA IP

| path | what |
|---|---|
| `ip_design/uhd_ip/` | the UHD data-plane cores (udp_streamer, udp_player, axis_pkt_arb, ch_interleave, tx/rx_beamformer): RTL, xsim testbenches, `make package` |
| `ip/uhd_ip/` | those cores packaged (`user.org:uhd:<core>:1.0`): generated by `make package`, never edited |
| `ip_design/cmac_100g/` | the 100G CMAC + split-quad GT wrapper RTL; instantiated in each build's generated RTL top, not in the block design |
| `ip/iprepo/dual_rf_adc_iq_merger_1.0`, `ip/iprepo/dual_channel_rf_adc_iq_packer_1.0` | the ZCU208 dual RF-ADC I/Q joiners (packaged in place, with their HDL and testbench) |

The same relative layout as SPEAR's `hw_design/`, so packaging and the board
flows find each other unchanged. Each subdirectory's README/AGENTS (from SPEAR)
has the details.
